# Northline five-minute demo script

1. **Admin overview — 60 seconds**
   - Open the Northline URL.
   - Log in with `admin@construction.local` / `Admin123!`.
   - Stay on **Overview**.
   - Point out the three live projects, portfolio budget, non-zero attendance records, and open safety issues.
   - Say: “This is the operating picture a manager normally has to assemble manually.”

2. **Finance visibility — 75 seconds**
   - Click **Finance** in the left navigation.
   - Start with **Budget versus actual**.
   - Highlight **مستشفى النور التخصصي**: it is intentionally slightly over budget so the alert is visible immediately.
   - Point out the category-level expense list for materials, labor, and equipment rental.
   - Say: “Before, this variance might appear weeks later. Here, it is visible while the team can still act.”

3. **Safety response — 60 seconds**
   - Click **Safety issues**.
   - Point out the open high-severity **Crane malfunction on floor 3** issue.
   - Show the mix of open, in-progress, and resolved statuses.
   - Say: “The issue is prioritized and traceable instead of being buried in a message thread.”

4. **Role-based access — 90 seconds**
   - Click **Sign out**.
   - Log in with `worker@construction.local` / `Worker123!`.
   - Compare the navigation with the admin view: no Admin & audit or Finance navigation, and only assigned operational data is visible.
   - Say: “The same system gives each role the information needed for the job without exposing unrelated financial or administrative data.”

5. **Close — 35 seconds**
   - Return to the one-pager and point to the Before/After table.
   - Close with: “We propose a free or discounted pilot on one active project. We can establish a live baseline for labor, cost, materials, and safety, then measure the improvement with your team.”
